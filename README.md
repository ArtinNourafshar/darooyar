# دارویار 🩺 | Darooyar

**یادآور دارو و وعدهٔ غذایی خانوادگی + دستیار سلامت — فارسی، راست‌چین و بدون سرور**

![Flutter](https://img.shields.io/badge/Flutter-3.x-02569B?logo=flutter&logoColor=white)
![Platforms](https://img.shields.io/badge/platform-Windows%20%7C%20Android-333?logo=windows&logoColor=white)
![Tests](https://img.shields.io/badge/tests-56%20passed-4c1?logo=pytest&logoColor=white)
![Offline](https://img.shields.io/badge/data-local%20SQLite-007EC6?logo=sqlite&logoColor=white)

دارویار یک اپلیکیشن **فلاتر** برای یادآوری مصرف دارو و وعده‌های غذایی اعضای خانواده است؛ با تمرکز بر سالمندان و خانواده‌هایی که چند داروی زمان‌بندی‌شده دارند. همهٔ داده‌ها **به‌صورت محلی** (SQLite) ذخیره می‌شوند، رابط کاربری **فارسی و راست‌چین** است و **اینترنت فقط و فقط با فعال‌سازی اختیاری دستیار هوشمند** استفاده می‌شود.

> **English:** Darooyar is a Persian, RTL family medication & meal reminder with health tracking and an opt-in Gemini assistant for Windows and Android. All data stays in a local SQLite database — no account, no server; internet is used only if you explicitly enable the AI assistant.

## امکانات

| بخش | جزئیات |
|---|---|
| **افراد خانواده** | پروفایل چندنفره با نام، توضیح و **رنگ اختصاصی** هر فرد برای تشخیص سریع |
| **داروها** | ثبت نام دارو، دوز، شکل مصرف و **چند نوبت ساعتی در روز** برای هر فرد |
| **صفحهٔ «امروز»** | نوبت‌های دارو و وعده‌های امروز با وضعیت‌های «در انتظار / خورده شد / نخوردم / مصرف نشده»، تأیید یک‌لمسی و کارت پیشرفت روز |
| **وعده‌های غذایی** | برنامهٔ روزانهٔ صبحانه/ناهار/شام (+ وعدهٔ دلخواه)، یادآوری در ساعت تعیین‌شده و ثبت «خورده شد / نخوردم» |
| **زنگ دقیق ساعت** | نوتیفیکیشن **زنگ‌دار درست در ساعت مقرر** با صدای حلقه‌ای و باز شدن تمام‌صفحه در اندروید؛ دکمه‌های **«قطع»** و **«چرت ۵ دقیقه‌ای»**؛ در ویندوز اعلان سناریوی alarm با صدای حلقه‌ای. زمان‌بندی دقیق (exact alarm) در اندروید و نگاشت ۷ روزهٔ جلوتر در ویندوز |
| **شاخص‌های بدن** | ثبت **فشار خون، قند خون، وزن، چربی بدن، ساعت و کیفیت خواب، دور کمر**؛ محاسبهٔ **BMI** با دسته‌بندی WHO و **نمودار خطی ۳۰ روزه** هر شاخص + ویرایش قد |
| **گزارش و فعالیت** | بازه‌های «امروز / هفتگی / ماهیانه / سالیانه»، آمار پایبندی، **نمودار ستونی مصرف** (خورده شد در برابر مصرف نشده) به تفکیک ساعت/روز/ماه شمسی، **جریان یکپارچهٔ فعالیت** (دارو + وعده + شاخص سلامت) و **خروجی PDF** راست‌به‌چپ |
| **دستیار سلامت و تغذیه** | دستیار هوشمند **Google Gemini** (فقط با کلید API شما، opt-in): چت تغذیه‌ای، **بررسی روزانهٔ سلامت/تغذیه** از روی جمع‌بندی آمار و تحلیل شاخص‌های بدن (فشار خون، BMI، خواب، چربی، قند، تغذیه) |
| **تاریخ شمسی** | ذخیرهٔ میلادی، نمایش شمسی با ارقام فارسی |
| **تم و دسترس‌پذیری** | تم گرادیانی برند (**نارنجی + آبی آسمانی**)، حالت روشن/تیره، مقیاس فونت کاربر ۰٫۸ تا ۱٫۸، چیدمان رسپانسیو از موبایل تا پنجره‌های عریض دسکتاپ (۵ تب موبایل + ریل ۶ مقصدی دسکتاپ) |

### حریم خصوصی و اینترنت

- **پیش‌فرض کاملاً آفلاین:** بدون فعال‌سازی دستیار، برنامه حتی یک بایت هم به اینترنت نمی‌فرستد؛ مجوز `INTERNET` فقط برای دستیار opt-in گذاشته شده و همهٔ داده‌ها محلی می‌مانند.
- **دستیار فقط opt-in:** اینترنت تنها زمانی استفاده می‌شود که خودتان کلید API گوگل را وارد و دستیار را فعال کنید؛ در این حالت فقط **جمع‌بندی آمار خلاصه‌شده** (تعداد نوبت‌های خورده‌شده، میانگین شاخص‌های سلامت و…) همراه با پیام شما ارسال می‌شود — **نه نام داروها، نه اطلاعات هویتی**.
- **بدون حساب و سرور:** کلید API فقط در پایگاه‌دادهٔ محلی شما می‌ماند؛ هیچ سرور واسطی در کار نیست.
- **بدون بک‌آپ سیستم:** `android:allowBackup="false"` تا دیتابیس و گزارش‌ها بدون اجازهٔ شما روی Google Drive بک‌آپ نروند.
- **بدون واسط:** پایگاه‌دادهٔ `darooyar.db` در پوشهٔ دادهٔ خود برنامه می‌ماند و خروجی PDF در پوشهٔ `darooyar_reports/` داخل «اسناد» ذخیره می‌شود.
- **نوتیفیکیشن‌های بی‌نام:** روی قفل‌صفحه فقط وضعیت یادآوری دیده می‌شود، نه نام و دوز دارو.
- داده‌های سلامتی خانواده حتی در اختیار توسعه‌دهنده هم قرار نمی‌گیرد.

## شروعٔ سریع

### پیش‌نیازها

- **Flutter SDK** با نسخهٔ Dart `^3.13`
- برای اندروید: Android SDK + JDK 17
- برای ویندوز: Visual Studio 2022 با کامپوننت *Desktop development with C++*

### نصب و اجرا

```bash
git clone https://github.com/ArtinNourafshar/darooyar.git
cd darooyar

flutter pub get

# ویندوز
flutter run -d windows

# اندروید (دستگاه یا شبیه‌ساز متصل)
flutter run -d android
```

هیچ متغیر محیطی سفارشی یا سرویس جانبی لازم نیست.

### کیفیت و تست

```bash
flutter analyze   # بدون هیچ خطایی
flutter test      # ۵۶ تست (منطقی + ویجت)
```

پوشش تست: ارقام و تاریخ فارسی، ساخت نوبت‌ها و وضعیت‌ها (شامل نوبت‌های پیش از ثبت دارو)، بازه‌ها و آمار گزارش + **گروه‌بندی ستون‌های نمودار** (ساعت/روز/ماه شمسی)، یکتایی شناسه‌های نوتیفیکیشن (دارو، وعده، چرت، کپی‌های ۷ روزهٔ ویندوز)، و تست‌های ویجت پوسته (راست‌چین، تم مات، ناوبری ۵بخشی، ریل دسکتاپ ۶مقصدی، باز شدن صفحهٔ افراد).

### ساخت خروجی ریلیز

```bash
# اندروید → build/app/outputs/flutter-apk/app-release.apk
flutter build apk --release

# ویندوز → build/windows/x64/runner/Release/
flutter build windows --release
```

نسخه‌های منتشرشده (exe تک‌فایل ویندوز و APK اندروید) در بخش [Releases](../../releases) قرار می‌گیرند.

### نکات فنی

- **پایگاه‌داده:** حذف فرد یا دارو با `ON DELETE CASCADE` سوابق مرتبط را پاک می‌کند؛ کلید یکتای نوبت `(medication_id, log_date, log_time)` با `ConflictAlgorithm.replace` است تا تأیید مجدد، وضعیت قبلی را جایگزین کند.
- **تاریخ:** ذخیره به‌صورت میلادی `yyyy-MM-dd` و تبدیل به شمسی فقط هنگام نمایش — محاسبات بازهٔ گزارش‌ها ساده و بدون ابهام می‌ماند.
- **نوبت روز ثبت:** ساعت دقیق ثبت دارو (`created_time`) ذخیره می‌شود تا دارویی که ساعت ۱۵ ثبت شده، نوبت ۰۸ همان روز را «مصرف نشده» نبیند و درصد پایبندی خراب نشود.
- **گزارش:** بازهٔ «همهٔ تاریخچه» حداکثر ۳۶۵ روز است و جدول با رندر تنبل (`SliverList.builder`) ساخته می‌شود تا سال‌ها داده هم کرش نکند.
- **نیمه‌شب:** نوبت‌هایی که از بیست‌چهار رد می‌شوند در ساخت نوبت‌های روز لحاظ شده‌اند.
- **PDF:** جدول برعکسِ چیده می‌شود (تاریخ در سمت راست) و هر صفحه ۲۲ ردیف دارد.
- **زنگ ساعتی:** هر یادآوری یک نوتیفیکیشن زنگ‌دار با صدای حلقه‌ای است (WLC `alarm_beep.wav` در `android/app/src/main/res/raw/`)؛ اندروید با `exactAllowWhileIdle` و full-screen intent درست در ساعت مقرر زنگ می‌زند و ویندوز چون زمان‌بندی تکی دارد، برای ۷ روز آینده کپی‌های جدا می‌سازد. همهٔ شناسه‌ها در فضاهای جدا (دارو / وعده / درون‌برنامه / چرت / کپی روز) اند تا لغو یکی، دیگری را خراب نکند — پوشش‌داده‌شده با تست.
- **دستیار:** فعال‌سازی فقط با کلید API کاربر (opt-in)؛ بررسی روزانهٔ سلامت تنها پس از تأیید پیکربندی و یک‌بار در روز اجرا می‌شود و خلاصهٔ ارسالی فقط آمار عددی خلاصه‌شده است.
- **رسپانسیو:** `MediaQuery.withClampedTextScaling` با محدودهٔ ۰٫۸–۱٫۸ و شکستنی از Compact (زیر ۶۰۰) تا Extended (بالای ۱۱۰۰).

## لایسنس فونت

فونت **ایران‌یکان (IRANYekan)** از پکیج npm `@alibaba-aero/iranyekan` گرفته شده و تحت لایسینس **MIT** منتشر شده است.
وزن‌های ۱۰۰ تا ۹۰۰ در `assets/fonts/` قرار دارند و در `pubspec.yaml` ثبت شده‌اند.
پیش از انتشار عمومی نسخهٔ باینری، متن لایسنس MIT فونت را در کنار اعلان‌های برنامه بگنجانید.
